# Purple OS — System Assets & Licenses

This directory contains official visual assets, artwork, and fonts for Purple OS.

## 1. Wallpapers (`assets/artwork/`)

Inspired by anime cosmic fantasy and Hollow Purple-like violet energy:
- **`wallpaper_cosmic_purple.png`**: Primary 16:9 widescreen cosmic vortex wallpaper (1920x1080).
- **`wallpaper_3840x2160.png`**: High-resolution 4K Ultra-HD variant (3840x2160).
- **`wallpaper_1920x1080.png`**: Standard Full-HD variant (1920x1080).
- **`wallpaper_1024x768.bmp`**: Uncompressed 24/32-bit BMP asset for 1024x768 QEMU/Bochs VBE display modes.
- **`wallpaper_1280x800.bmp`**: Uncompressed 24/32-bit BMP asset for 1280x800 display modes.

**Composition details:**
- Gigantic swirling violet cosmic vortex in a dark indigo sky.
- Layered mountain silhouettes and rocky outcrop with a traditional Japanese torii gate.
- Calm reflective lake mirroring the violet vortex and luminous nebulae.
- Floating glowing purple particles and atmospheric depth.
- Color palette: Deep navy shadows (`#0a0518`), electric violet highlights (`#a855f7`), magenta radiance (`#c084fc`), restrained soft pink accents (`#f472b6`).
- Zero people, characters, or text embedded in the wallpaper.

## 2. Fonts (`assets/fonts/`)

- **`NotoSans-Regular.ttf`**: Clean, geometric modern sans-serif typeface for UI elements, panels, and body text.
- **`NotoSans-Bold.ttf`**: Bold weight for window headers, title bars, and prominent indicators.
